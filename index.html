About Me

Hello! I'm Richard, a Software Test Automation Engineer who's passionate about quality. My journey into QA started when I realized how much confidence a solid automated test suite gives a team, and it grew into a career built around catching bugs before users ever see them.

I design and maintain end-to-end, API, and performance test frameworks, and I care deeply about reliable, maintainable tests that fit cleanly into CI/CD pipelines. I believe quality is a shared responsibility, and good automation is what makes fast releases safe.

Here are a few tools and technologies I work with regularly:

  • Cypress
  • Playwright
  • Selenium WebDriver
  • Postman & Bruno
  • REST Assured
  • JMeter
  • JavaScript / TypeScript
  • Java
  • Git & CI/CD
  • Jenkins / GitHub Actions
